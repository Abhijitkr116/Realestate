🏠 Real Estate | React Web Application

A modern and responsive Real Estate website built with React.js, designed to showcase properties and create an engaging digital experience for potential clients. The project focuses on clean UI, smooth animations, responsive design, and lead generation.

✨ Key Features
🏡 Modern real-estate property showcase
📱 Fully responsive design across devices
🎬 Smooth animations using Framer Motion
📩 Contact/lead forms powered by Web3Forms
🔔 User notifications using React Toastify
⚡ Component-based architecture with React
🎨 Clean and modern UI focused on user experience
🚀 Built with client acquisition and property presentation in mind
🛠️ Tech Stack

React.js • JavaScript • Framer Motion • Web3Forms • React Toastify • HTML5 • CSS3

This project demonstrates my ability to build modern, interactive, and conversion-focused frontend applications using React and modern web technologies.
